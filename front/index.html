Digital Social Score

Détection de toxicité · anonymisation RGPD · score de 0 à 100

API déployée sur Google Cloud (routes /score et /health, clé dans l'en-tête X-API-Key). Ton texte part en HTTPS vers ce serveur, qui l'anonymise avant l'analyse ; il n'est ni stocké ni journalisé. Une seule version du modèle (DistilBERT). Le serveur renvoie le texte anonymisé et nettoyé (affichés, et seuls gardés dans l'historique de l'onglet) ; pas de vue « Pipeline », qui demande les positions des éléments masqués. La clé reste dans ce champ, elle n'est jamais enregistrée.
