- [loadtest/RAPPORT.md](../loadtest/RAPPORT.md) : rapport complet des tests de charge (TP1, étape 5, repris en annexe B).
- [supervision/INCIDENTS.md](../supervision/INCIDENTS.md) : registre des incidents (TP1, étape 6).
